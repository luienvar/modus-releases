# Modus releases

Signed builds of [Modus](https://getmodus.dev), a local-first workspace for AI coding agents.

- **macOS (Apple Silicon):** a DMG signed with a Developer ID and notarized by Apple.
- **Linux (amd64):** a `.deb` package.

Every update package also carries a minisign signature, checked by the app's updater before it installs anything. Download the latest version from [getmodus.dev](https://getmodus.dev) or from the [latest release](https://github.com/luienvar/modus-releases/releases/latest).
